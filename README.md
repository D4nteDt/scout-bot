# SteamScope — интеллектуальный Telegram-бот для мониторинга рынка Steam
Telegram-бот для автоматического отслеживания, анализа и краткосрочного прогнозирования цен на внутриигровые предметы на торговой площадке Steam.

 Возможности
- Добавление предмета в отслеживание по ссылке со Steam Market
- Визуализация динамики цен (графики)
- Краткосрочный прогноз на основе анализа временных рядов
- Мгновенные уведомления при достижении заданного ценового порога
- Список отслеживаемых предметов
- Удаление предметов из отслеживания

 Как это работает
- Fetch-модуль — асинхронный сбор данных с помощью Steam API
- База данных — хранит историю цен (SQLite / PostgreSQL)
- Analyzer — фильтрует рыночный шум с помощью медианного фильтра и фильтра Калмана, а также строит краткосрочные прогнозы на основе анализа временных рядов
- Бот — интерфейс в Telegram

 Технологии
- Python 3.11+
- Aiogram (API Telegram-бота)
- Aiohttp (асинхронные запросы)
- Pandas / NumPy (анализ данных)
- SQLite → PostgreSQL
- Git / GitHub
